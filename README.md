# Язык R

Материалы курса и исходники сайта: <https://r-lang-vladissta.github.io/r-course/>.

Главная страница редактируется в файле `index.qmd`.



## Сдача домашних заданий

Кнопка «Сдать работу» открывает страницу `submit.qmd` со встроенной Яндекс Формой.
Работы отправляются в аккаунт владельца формы; локальный сервер не принимает
эти отправки. Вложения нужно сохранять из Яндекс Форм на Диск или компьютер.

Для локального просмотра после `quarto render` запустите
`python3 scripts/local-homework-server.py` и откройте <http://localhost:8765>.
Страница со встроенной формой также работает на GitHub Pages без отдельного
обработчика загрузок. Для заполнения нужен доступ к интернету.

Ссылка формы: <https://forms.yandex.ru/u/6ac4e95d95add5223f150ae2>.
Чтобы сменить форму, обновите ссылку, адрес iframe и его name в `submit.qmd`.

Старая локальная проба сохранена в `scripts/local-homework-server.py`; её
тестовые работы находятся в `submissions/homework-01/` и исключены из Git.
