3.1 Аргументы функций

  • Аргумент – значение, которое передают функции.
  • Позиционный аргумент определяется своим местом в вызове.
  • Именованный аргумент записывают как имя = значение.
  • Аргумент по умолчанию можно пропустить: функция использует заранее заданное значение.

5 Сравнения и логические выражения

При сравнении известных значений получается TRUE или FALSE. Если участвует NA, результат также может быть NA.

Оператор Проверка
==, != равно, не равно
<, > меньше, больше
<=, >= меньше или равно, больше или равно
! НЕ
&, && И
|, || ИЛИ

& и | применяются в том числе поэлементно. && и || работают с одиночными условиями и прекращают вычисление, когда результат уже известен.

[1] TRUE
5 != 3
[1] TRUE
3 < 5
[1] TRUE
5 >= 5
[1] TRUE
!TRUE
[1] FALSE

[1] FALSE
TRUE | FALSE
[1] TRUE
(5 > 3) & (10 < 20)
[1] TRUE
(5 > 10) | (10 < 20)
[1] TRUE
FALSE && unknown_value
[1] FALSE
TRUE || unknown_value
[1] TRUE

6 Служебный синтаксис и ошибки

Перевод строки завершает синтаксически законченное выражение. Незаконченное выражение можно продолжить на следующих строках.

total_volume <- sample_count *
  volume_per_sample

round(
  3.14159,
  digits = 2
)
[1] 3.14
x <- 5; y <- 6; x + y
[1] 11
{
  sample_count <- 24
  replicate_count <- 2
  sample_count * replicate_count
}
[1] 48

Фигурные скобки {} объединяют несколько выражений в один блок; результатом блока становится значение последнего выражения.
