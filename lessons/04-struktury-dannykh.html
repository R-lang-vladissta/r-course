Занятие 4. Матрицы, массивы и факторы

Как хранить разные виды данных до работы с таблицами

1 Матрицы

На прошлом занятии мы работали с векторами: у каждого элемента вектора одна позиция. Если у каждого образца есть несколько измерений, данные удобно расположить по двум направлениям. Матрица (matrix) – набор значений в строках и столбцах. Как в линейной алгебре, её элемент можно обозначить \(a_{ij}\): \(i\) указывает строку, \(j\) – столбец. В R все значения матрицы имеют один тип, как и у вектора.

1.1 Как создать матрицу

Пусть строки соответствуют трём образцам, а столбцы – измерениям до и после обработки. Функция matrix() создаёт матрицу из вектора. Аргумент nrow задаёт число строк; по умолчанию значения заполняют столбцы сверху вниз. Поэтому в векторе ниже сначала идут три измерения до обработки, затем три измерения после неё. Сигнал указан в условных единицах.

signal_values <- c(0.42, 0.51, 0.63, 0.48, 0.70, 0.59)
signal_matrix <- matrix(signal_values, nrow = 3)
signal_matrix
     [,1] [,2]
[1,] 0.42 0.48
[2,] 0.51 0.70
[3,] 0.63 0.59

Получилась матрица из трёх строк и двух столбцов. Например, во второй строке стоят измерения второго образца: 0.51 и 0.70.

Порядок исходных значений имеет значение

Если значения записаны парами «до, после» для каждого образца, обычное заполнение по столбцам свяжет их не с теми образцами. Для такого порядка укажите byrow = TRUE: значения заполнят строки слева направо.

matrix(c(0.42, 0.48, 0.51, 0.70, 0.63, 0.59),
       nrow = 3, byrow = TRUE)
     [,1] [,2]
[1,] 0.42 0.48
[2,] 0.51 0.70
[3,] 0.63 0.59

1.2 Размеры и имена

Знакомая по векторам идея имён работает и здесь. Функции rownames() и colnames() позволяют задать или получить имена строк и столбцов. Функция dim() возвращает два размера матрицы: число строк и столбцов. Если нужен один размер, используйте nrow() или ncol().

rownames(signal_matrix) <- c("S1", "S2", "S3")
colnames(signal_matrix) <- c("before", "after")

signal_matrix
   before after
S1   0.42  0.48
S2   0.51  0.70
S3   0.63  0.59
dim(signal_matrix)
[1] 3 2
nrow(signal_matrix)
[1] 3
ncol(signal_matrix)
[1] 2

dim(signal_matrix) показывает 3 2: три строки и два столбца. Теперь по именам видно, какое значение относится к каждому образцу и моменту времени.

1.3 Выбор и изменение значений

У вектора внутри квадратных скобок мы указывали один индекс. У матрицы их два, разделённых запятой: матрица[строка, столбец]. Для выбора можно использовать номера или заданные выше имена. Пустое место означает «все строки» или «все столбцы»:

signal_matrix[2, 1]
[1] 0.51
signal_matrix["S2", "after"]
[1] 0.7
signal_matrix[, "after"]
  S1   S2   S3 
0.48 0.70 0.59 
signal_matrix["S2", ]
before  after 
  0.51   0.70

Первое выражение возвращает сигнал образца S2 до обработки, второе – после неё. Третье извлекает все сигналы после обработки, четвёртое – оба сигнала образца S2. Извлечённый столбец можно использовать в расчёте:

mean(signal_matrix[, "after"])
[1] 0.59

Для исправления одного измерения координаты ставят слева от присваивания:

signal_matrix["S2", "after"] <- 0.68
signal_matrix
   before after
S1   0.42  0.48
S2   0.51  0.68
S3   0.63  0.59

Здесь изменяется только значение в строке S2 и столбце after.

Текст превратит измерения в текст

Если добавить идентификаторы как ещё один столбец, числа тоже станут текстом:

matrix(c(4.1, 5.0, "B01", "B02"), nrow = 2)
     [,1]  [,2] 
[1,] "4.1" "B01"
[2,] "5"   "B02"

Такие значения уже нельзя использовать в числовом расчёте. Имена строк обозначают образцы, сохраняя числовой тип измерений.

2 Массивы

У матрицы две координаты. Если для каждого образца есть результаты в два момента времени, полученные двумя методами, нужна третья: образец, время, метод. Такой объект называют массивом (array). Матрица – двумерный случай массива. Трёхмерный массив можно представить как стопку матриц; элемент задают тремя индексами \(a_{ijk}\). Это похоже на запись многомерных объектов в математике, которые иногда называют тензорами.

Функция array() создаёт массив из вектора. В dim = c(3, 2, 2) указаны размеры трёх направлений: 3 образца, 2 момента времени и 2 метода. Ниже первый слой содержит сигналы метода A, второй – метода B. Внутри слоя строки соответствуют образцам, столбцы – измерениям до и после обработки. Сигналы указаны в условных единицах.

signal_array <- array(
  c(0.42, 0.51, 0.63, 0.48, 0.70, 0.59,
    0.40, 0.49, 0.60, 0.46, 0.67, 0.57),
  dim = c(3, 2, 2)
)

dim(signal_array)
[1] 3 2 2
signal_array[, , 2]
     [,1] [,2]
[1,] 0.40 0.46
[2,] 0.49 0.67
[3,] 0.60 0.57
signal_array[2, 2, 2]
[1] 0.67

dim(signal_array) подтверждает размеры. В signal_array[, , 2] выбраны все образцы и оба момента времени для второго метода; последнее выражение возвращает одно измерение по трём координатам: второй образец, после обработки, метод B.

3 Факторы

До сих пор мы чаще работали с числовыми измерениями: концентрацией, сигналом, pH. Но переменная может обозначать категорию, а не число.

Переменная Пример значений Что важно
Числовая концентрация: 4.1, 5.0 мг/л Можно вычислить среднее
Категориальная без естественного порядка группа: контроль, лечение Можно сравнить группы и подсчитать их численность
Категориальная с порядком качество: низкое, среднее, высокое Порядок категорий имеет смысл

Названия групп можно хранить текстовым вектором, но тогда R не знает, какие категории допустимы и как их упорядочить. Фактор (factor) – это вектор для категориальных данных с дополнительным набором уровней (levels). Уровни задают названия категорий и их порядок. Это полезно при подсчёте наблюдений по группам, сортировке и построении графиков. Например, у группы лечения уровни могут быть control и treated, а у оценки качества – low, medium и high.

Посмотрим, как сортируется обычный текстовый вектор с оценками качества. Функция sort() располагает его значения по алфавиту:

quality <- c("medium", "high", "low", "medium", "high")
sort(quality)
[1] "high"   "high"   "low"    "medium" "medium"

Алфавитный порядок не отражает порядок качества. Функция factor() создаёт фактор из вектора; аргумент levels задаёт уровни в нужном порядке. Функция levels() показывает этот набор:

quality_factor <- factor(
  quality,
  levels = c("low", "medium", "high")
)

quality_factor
[1] medium high   low    medium high  
Levels: low medium high
levels(quality_factor)
[1] "low"    "medium" "high"  
sort(quality_factor)
[1] low    medium medium high   high  
Levels: low medium high

Теперь sort() использует порядок уровней. При этом каждый элемент фактора по-прежнему обозначает категорию конкретного образца. Уровни могут включать и категорию, которая не встретилась в данной выборке. Если нужно, чтобы R также разрешал сравнения категорий через < и >, при создании фактора указывают ordered = TRUE; для показанной сортировки это не требуется.
