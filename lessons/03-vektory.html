Занятие 3. Векторы

Создание, вычисления и отбор элементов

1 Что такое вектор

Вектор – объект R, в котором хранится упорядоченная последовательность значений. Например, в одном векторе можно сохранить результаты измерения концентрации для нескольких образцов:

concentration <- c(12.4, 15.1, 13.8, 14.6)
concentration
[1] 12.4 15.1 13.8 14.6
  • Порядок значений сохраняется
  • R не сортирует значения автоматически
  • Значения могут повторяться

Функция length() возвращает длину вектора – количество хранящихся в нём значений:

length(concentration)
[1] 4

Даже одно значение в R представлено как вектор длины 1:

temperature <- 36.7
length(temperature)
[1] 1

1.1 Функция c()

Функция c() объединяет переданные через запятую значения в вектор:

sample_group <- c("control", "treatment", "treatment", "control")
sample_group
[1] "control"   "treatment" "treatment" "control"  
quality_check <- c(TRUE, TRUE, FALSE, TRUE)
quality_check
[1]  TRUE  TRUE FALSE  TRUE
Замечание

Видно, что в векторах можно хранить разные виды данных: числа, текст, логические значения и т.д. Чуть позже мы разберём, как это связано с типом самого вектора.

Внутри c() можно указать и другие созданные векторы:

c(1, c(2, 3), c(4, 5))
[1] 1 2 3 4 5
morning <- c(12.4, 15.1)
evening <- c(13.8, 14.6)

all_measurements <- c(morning, evening)
all_measurements
[1] 12.4 15.1 13.8 14.6

morning и evening не остаются отдельными векторами внутри all_measurements: их элементы последовательно соединяются в один вектор.

Почему функция называется c()

Название c() – сокращение от combine.

1.2 Другие способы удобно создавать векторы

Иногда не обязательно перечислять каждый элемент вручную!

1.2.1 Оператор :

С помощью : можно создать последовательность чисел с шагом 1 при возрастании или −1 при убывании. Границы последовательности не обязаны быть целыми.

1:6
[1] 1 2 3 4 5 6
6:1
[1] 6 5 4 3 2 1
-2:2
[1] -2 -1  0  1  2
c(1:3, 2:4)
[1] 1 2 3 2 3 4

1.2.2 Функция seq()

seq() (от sequence) используют когда:

  • Нужен шаг не равный 1
seq(from = 0, to = 20, by = 5)
[1]  0  5 10 15 20
  • Нужно заданное кол-во элементов
seq(from = 0, to = 1, length.out = 5)
[1] 0.00 0.25 0.50 0.75 1.00

1.2.3 Функция rep()

Функция rep() (от repeat) создаёт вектор с повторяющимися элементами

  • Аргумент times – число повторений вектора целиком,
rep(c("control", "treatment"), times = 3)
[1] "control"   "treatment" "control"   "treatment" "control"   "treatment"
  • each – число повторений каждого элемента вектора:
rep(c("control", "treatment"), each = 3)
[1] "control"   "control"   "control"   "treatment" "treatment" "treatment"
Аргументы
Вызов Результат
rep(c("A", "B"), times = 3) A B A B A B
rep(c("A", "B"), each = 3) A A A B B B

ИТОГ: Основные способы создания векторов

Способ Когда удобен Пример
c() перечислить или объединить значения c(2, 5, 8)
: получить целые числа с шагом 1 1:5
seq() задать границы, шаг или длину seq(0, 10, by = 2)
rep() повторить значения rep(c("A", "B"), each = 2)

2 Тип вектора

Важное свойство вектора – все элементы имеют один общий тип.

Если вектор хранит character элементы, тип всего вектора – character, и так же для других типов.

Тип вектора Что хранит Пример
logical логические значения c(TRUE, FALSE)
integer целые числа c(1L, 2L)
double обычные числа c(1, 2.5)
character текст c("A", 'B') 
typeof(c(1.5, 2.0, 4.2))
[1] "double"
typeof(c("control", "sample", "sample"))
[1] "character"
  • Функции is.logical(), is.integer(), is.double() и is.character() могут проверять тип вектора:
is.logical(c(TRUE, FALSE))
[1] TRUE
is.double(c(1.5, 2.0, 4.2))
[1] TRUE

2.1 Приведение типов

Если попробовать написать в c() значения разных типов, то R приведёт их к общему типу, способному представить все переданные значения:

c(TRUE, 2)
[1] 1 2
c(1L, 2.5)
[1] 1.0 2.5
c(TRUE, 2, "sample")
[1] "TRUE"   "2"      "sample"

Направление приведения можно представить так:

logical → integer → double → character

Обобщаемость типов

Элементы каждого типа могут быть представлены в виде значений любого типа, который правее в схеме.

Например, double может хранить и 2, и 2.5, а character может записать их в виде текста. Это неявное приведение типов: R выполняет его автоматически.

typeof(c(TRUE, 2, "sample"))
[1] "character"
Одна строка изменяет весь вектор

Бывает, что пропущенные значения могут быть представлены текстом:

measurements <- c(12.4, 15.1, "нет измерения")
measurements
[1] "12.4"          "15.1"          "нет измерения"

Тогда весь вектор становится текстовым!

Для неизвестного измерения нужно использовать NA, а не текстовую пометку. NA обозначает отсутствие значения и оставляет тип вектора прежним

typeof(c(12.4, 15.1, NA))
[1] "double"
typeof(c("control", NA))
[1] "character"
  • Функции as.logical(), as.integer(), as.double() и as.character() выполняют явное преобразование типов.

Задание: план эксперимента

В эксперименте используют концентрации 0, 5, 10, 15 и 20 мкмоль/л. Каждую концентрацию испытывают на трёх образцах.

  1. Создайте вектор concentration с помощью seq().
  2. Создайте concentration_repeated, в котором каждая концентрация повторяется три раза.
  3. Создайте текстовый вектор sample_group, в котором по три раза повторяются названия пяти групп: "C0", "C5", "C10", "C15" и "C20".
  4. Проверьте длину и тип обоих длинных векторов.
  5. С помощью c() объедините concentration_repeated со строкой "control", сохраните результат и проверьте его тип. Объясните, что произошло.

3 Векторизованные вычисления

Одно из важнейших свойств векторов и языка R – возможность выполнять вычисления сразу для целой серии наблюдений. Не нужно повторять одну и ту же операцию для каждого элемента.

Такое свойство называется векторизованность.

  • Арифметическая операция применяется к каждому элементу:
signal <- c(10, 20, 30, 40)

signal * 2
[1] 20 40 60 80
signal / 10
[1] 1 2 3 4
  • Можно выполнить операцию и с векторами одинаковой длины. Тогда друг с другом взаимодействуют элементы на одинаковых позициях:
signal <- c(10, 20, 30, 40)
background <- c(1, 2, 1, 3)

signal - background
[1]  9 18 29 37
  • Оба вида операций могут сочетаться:
height <- c(1.80, 1.70, 1.75, 1.96)
weight <- c(120, 80, 90, 59)

bmi <- weight / height ^ 2
bmi
[1] 37.03704 27.68166 29.38776 15.35818

Результат такого вычисления – новый вектор той же длины.

3.1 Функции для работы с числовыми векторами

Некоторые функции применяются к каждому элементу вектора.

  • round() округляет каждое значение и возвращает вектор той же длины:
round(bmi, digits = 1)
[1] 37.0 27.7 29.4 15.4

Другие функции используют сразу все значения и вычисляют сводную характеристику вектора:

length(bmi) # Длина вектора
[1] 4
sum(bmi)  # Сумма элементов
[1] 109.4646
mean(bmi) # Среднее значение
[1] 27.36616
median(bmi) # Медиана
[1] 28.53471
min(bmi) # Минимальное значение
[1] 15.35818
max(bmi) # Максимальное значение
[1] 37.03704
range(bmi) # [min - max] 
[1] 15.35818 37.03704
Не все функции вычисляют одно значение

mean(), min() и max() возвращают по одному. range() возвращает вектор длины 2: наименьшее и наибольшее значения.

3.2 Ресайклинг

Векторы, между которыми происходит операция, не всегда имеют одинаковую длину.

Если один вектор короче, то R может “повторять” его, пока длины не совпадут. Это правило называется ресайклингом.

3.2.1 Вычитание одного числа из вектора.

Значение 2 повторяется для каждого элемента вектора measurement:

measurement <- c(10, 20, 30, 40)
measurement - 2
[1]  8 18 28 38
Шаг / номер элемента 1 2 3 4
Исходное измерение 10 20 30 40
Вычитаемый фон 2 2 2 2
Исправленное измерение 8 18 28 38

3.2.2 Короткий вектор содержит несколько значений.

Тут c(1, 2) повторяется дважды:

measurement + c(1, 2)
[1] 11 22 31 42
Вектор / номер элемента 1 2 3 4
measurement 10 20 30 40
c(1, 2) 1 2 1 2
Сумма 11 22 31 42

3.2.3 Длина одного вектора не кратна длине другого

Тогда R всё равно вычисляет результат, но выдаёт предупреждение:

measurement + c(1, 2, 3)
Warning in measurement + c(1, 2, 3): longer object length is not a multiple of
shorter object length
[1] 11 22 33 41
Вектор / номер элемента 1 2 3 4
measurement 10 20 30 40
c(1, 2, 3) 1 2 3 1 (повтор)
Сумма 11 22 33 41
Несовместимые длины могут дать правдоподобный результат

Предупреждение не останавливает вычисление. Поэтому ошибочный результат может оказаться похожим на правильный. Если ресайклинг не был запланирован, проверьте длины векторов с помощью length().

Задание: фоновая поправка

Шесть образцов поочерёдно измерили на двух каналах прибора: A, B, A, B, A, B. Измеренные сигналы равны 0.42, 0.51, 0.63, 0.48, 0.70 и 0.59. Фон канала A равен 0.04, а фон канала B – 0.06.

  1. Сохраните сигналы в signal, а два фоновых значения – в background.
  2. Вычтите соответствующий фон из каждого сигнала и сохраните результат в corrected_signal.
  3. Умножьте все исправленные сигналы на коэффициент 10.
  4. Округлите результаты до одного знака после десятичной точки.
  5. Рассчитайте среднее и диапазон исправленных сигналов.

4 Индексирование

Иногда нужен не весь вектор, а одно или несколько значений.

Каждый элемент в векторе имеет порядковый номер – индекс. Зная индекс нужных элементов, можно выбрать их из вектора.

Запомните!

В R индексация начинается с 1!!!

Индекс 1 2 3 4 5
Значение 12.4 15.1 13.8 14.6 11.9 
protein_concentration <- c(12.4, 15.1, 13.8, 14.6, 11.9)

Для выбора элемента по индексу:

  • Пишем название вектора
  • Приписываем рядом квадратные скобки []
  • Пишем внутри [] вектор нужных индексов (или один индекс)
protein_concentration[1]
[1] 12.4
protein_concentration[c(2, 4)]
[1] 15.1 14.6
protein_concentration[2:4]
[1] 15.1 13.8 14.6
Напоминалка: Круглые и квадратные скобки

Круглые скобки вызывают функцию: mean(x). Квадратные скобки выбирают часть объекта: x[2].

  • Индексы задают не только набор, но и порядок результата (один индекс можно указать несколько раз!):
protein_concentration[c(5, 1, 3)]
[1] 11.9 12.4 13.8
protein_concentration[c(2, 2, 4)]
[1] 15.1 15.1 14.6
  • Отрицательные индексы исключают указанные позиции:
protein_concentration[-3]
[1] 12.4 15.1 14.6 11.9
protein_concentration[c(-2, -4)]
[1] 12.4 13.8 11.9
Положительные и отрицательные индексы нельзя смешивать

x[c(1, -2)] не может одновременно означать «взять первый» и «исключить второй». R вернёт ошибку.

  • Если индекс выходит за границы вектора, то на этой позиции нет значения:
protein_concentration[7]
[1] NA
Индекс за границей не вызывает ошибку

R возвращает NA. Поэтому опечатка в индексе может не остановить код, а незаметно дать пропущенное значение.

4.1 Изменение элементов

Индексирование можно использовать и чтобы изменять элементы в векторе

measurements <- c(4.2, 5.1, 99, 6.0)

measurements[3] <- 5.4
measurements
[1] 4.2 5.1 5.4 6.0
measurements[c(2, 4)] <- c(5.0, 6.1)
measurements
[1] 4.2 5.0 5.4 6.1

4.2 Именованный вектор

Позиция не всегда помогает понять, к кому или к чему относится значение. На помощь приходят именованные векторы, где каждому значению вектора присвоено имя.

  • Элементам вектора можно дать имена при создании:
height <- c(Anna = 168, Boris = 181, Elena = 174, Pavel = 177)
height
 Anna Boris Elena Pavel 
  168   181   174   177
  • Можно сначала создать вектор, а затем присвоить его элементам вектор имён:
height <- c(168, 181, 174, 177)
names(height) <- c("Anna", "Boris", "Elena", "Pavel")

height
 Anna Boris Elena Pavel 
  168   181   174   177 
names(height)
[1] "Anna"  "Boris" "Elena" "Pavel"
names()

names(height) возвращает имена, а names(height) <- ... присваивает их.

  • Теперь именованный элемент можно извлечь по имени или по позиции:
height[c("Anna", "Pavel")]
 Anna Pavel 
  168   177 
height[3]
Elena 
  174
Когда одного именованного вектора становится мало

Именованный вектор удобен, пока для каждого объекта нужно хранить одну характеристику. Если для студентов добавить возраст, группу и результат теста, понадобятся несколько связанных векторов, которые придётся изменять и переставлять согласованно. Позднее мы познакомимся со структурами, которые удобнее хранят такие табличные данные.

Задание: исправляем измерения

Вектор ph содержит результаты измерения pH шести образцов. Значение четвёртого образца внесено неверно: вместо 7.3 записано 73.

ph <- c(7.1, 6.8, 7.0, 73, 7.2, 6.9)
sample_id <- c("S1", "S2", "S3", "S4", "S5", "S6")
  1. Извлеките первое, третье и пятое измерения.
  2. Покажите все измерения, кроме второго.
  3. Исправьте четвёртое значение.
  4. Присвойте элементам ph имена из sample_id.
  5. Извлеките pH образца S5 по имени.
  6. Найдите максимальный pH

5 Сортировка значений

Элементы в векторе можно упорядочивать по их значению.

Для этого удобны функции sort() и order(), которые несмотря на схожесть названий решают разные задачи.

signal <- c(0.72, 0.31, 0.56, 0.44, 0.83)

sort(signal)
[1] 0.31 0.44 0.56 0.72 0.83
sort(signal, decreasing = TRUE)
[1] 0.83 0.72 0.56 0.44 0.31
order(signal)
[1] 2 4 3 1 5
  • sort(signal) возвращает значения, расположенные по возрастанию.
  • sort(signal, decreasing = TRUE) возвращает значения по убыванию.
  • order(signal) возвращает индексы: в каком порядке нужно взять исходные элементы.

Эти два выражения ниже дают одинаковый результат:

sort(signal)
[1] 0.31 0.44 0.56 0.72 0.83
signal[order(signal)]
[1] 0.31 0.44 0.56 0.72 0.83
order() возвращает не значения, а индексы

Индексы из order() можно применить не только к самому signal, но и к другому связанному вектору. Так можно одинаково переставить измерения и имена образцов.

Отсортируем студентов по росту:

students_height <- c(168, 181, 174, 177)
students_names <- c("Anna", "Boris", "Elena", "Pavel")

students_order <- order(students_height)
students_names[students_order]
[1] "Anna"  "Elena" "Pavel" "Boris"

Задание: образцы по возрастанию сигнала

Идентификаторы образцов и их сигналы хранятся в двух векторах. Значения на одинаковых позициях относятся к одному образцу.

sample_id <- c("S1", "S2", "S3", "S4", "S5")
signal <- c(0.72, 0.31, 0.56, 0.44, 0.83)
  1. Отсортируйте сигналы по возрастанию.
  2. Сохраните индексы, которые упорядочивают сигнал, в объект signal_order.
  3. Используйте signal_order, чтобы расположить sample_id и signal в одинаковом порядке.
  4. Присвойте элементам signal имена из sample_id и отсортируйте именованный вектор по убыванию.
  5. Найдите максимальный сигнал

6 Логические векторы

Для векторов подходят те же операторы сравнения и логические операторы: >, >=, <, <=, ==, !=, &, | и !.

  • Операция выполняется для каждого элемента, поэтому результатом становится логический вектор той же длины:
temperature <- c(36.4, 37.1, 38.2, 36.8)
temperature >= 37
[1] FALSE  TRUE  TRUE FALSE

Каждое TRUE или FALSE относится к значению на той же позиции.

  • Условия тоже можно объединять
is_normal <- (temperature >= 36.5) & (temperature <= 37.2)
is_normal
[1] FALSE  TRUE FALSE  TRUE
is_fever <- temperature > 38 | temperature < 36
!is_fever
[1]  TRUE  TRUE FALSE  TRUE
  • Логический вектор можно использовать и при сравнении текста:
group <- c("control", "treatment", "control", "placebo")
group == "control"
[1]  TRUE FALSE  TRUE FALSE

6.1 Логическое индексирование

Логический вектор можно поместить внутрь квадратных скобок [], чтобы отфильтровать элементы.

Такой логический вектор часто называют маской: TRUE оставляет элемент на данной позиции, а FALSE его не пропускает.

measurements <- c(4.2, 8.1, 3.7, 6.4)
is_high <- measurements >= 5 # маска

is_high # маска
[1] FALSE  TRUE FALSE  TRUE
measurements[is_high]
[1] 8.1 6.4
Позиция 1 2 3 4
Исходный вектор 4.2 8.1 3.7 6.4
Проверка >= 5 (маска) FALSE TRUE FALSE TRUE
Действие не брать взять не брать взять
Результат – 8.1 – 6.4

Второе значение 8.1 проходит проверку, поэтому второй элемент попадает в результат. Первый не проходит проверку и не отбирается.

  • То же действие можно записать одной строкой:
measurements[measurements >= 5]
[1] 8.1 6.4
  • Одна маска может отбирать связанные элементы из нескольких векторов:
student_name <- c("Daniel", "Sasha", "Robert", "Alice")
age <- c(15, 32, 18, 8)

is_adult <- age >= 18 # Маска
student_name[is_adult]
[1] "Sasha"  "Robert"
age[is_adult]
[1] 32 18
Маска должна соответствовать исходному вектору

Обычно длина маски должна совпадать с длиной отбираемого вектора. Более короткая логическая маска будет повторена по правилу ресайклинга. Это может незаметно отобрать не те значения.

Логическое индексирование можно поместить слева от присваивания

Тогда заменяются все элементы, удовлетворяющие условию:

measurements <- c(4.2, 8.1, 3.7, 6.4)
measurements[measurements < 4] <- NA
measurements
[1] 4.2 8.1  NA 6.4
  • Функция which() превращает логическую маску в индексы тех позиций, где стоит TRUE:
is_high <- c(FALSE, TRUE, FALSE, TRUE)
which(is_high)
[1] 2 4
Как найти имя, связанное с максимальным значением

Имя студента с наибольшим ростом можно найти поэтапно:

max(height)
[1] 181
which.max(height)
Boris 
    2 
names(height)[which.max(height)]
[1] "Boris"

which.max(height) возвращает позицию первого максимального значения. Затем эта позиция используется для извлечения имени.

6.2 Функции для логических векторов

В арифметических вычислениях TRUE преобразуется в 1, а FALSE – в 0.

  • Поэтому sum() считает количество TRUE:
quality_check <- c(TRUE, FALSE, TRUE, FALSE, TRUE, TRUE)

sum(quality_check)
[1] 4
  • А mean() считает долю TRUE
mean(quality_check)
[1] 0.6666667
  • any() проверяет, есть ли хотя бы один TRUE:
any(quality_check)
[1] TRUE
  • all() – все ли элементы равны TRUE
all(quality_check)
[1] FALSE

6.3 Оператор %in%

Иногда нужно проверить, входят ли значения вектора в заданный набор.

Оператор %in% возвращает для каждого элемента слева, найден ли он среди значений справа:

sample_group <- c("control", "treated", "placebo", "treated", "excluded")
allowed_group <- c("control", "placebo")

sample_group %in% allowed_group
[1]  TRUE FALSE  TRUE FALSE FALSE
  • Удобно использовать для логического индексирования
sample_group[sample_group %in% allowed_group]
[1] "control" "placebo"
Не путайте == и %in%

Выражение sample_group == c("control", "placebo") попарно сравнивает два вектора (учитывая ресайклинг).

Результат может выглядеть правдоподобно, но это не проверка принадлежности элементов набору, для которой нужен %in%.

6.4 Повторяющиеся и уникальные значения

  • Функция unique() возвращает вектор уникальных значений, сохраняя порядок их первого появления:
sample_id <- c("S01", "S02", "S03", "S02", "S04", "S01")
unique(sample_id)
[1] "S01" "S02" "S03" "S04"
  • Функция duplicated() возвращает логическую маску, где FALSE значит, что значение встретилось впервые, а TRUE – что оно уже появлялось раньше:
duplicated(sample_id)
[1] FALSE FALSE FALSE  TRUE FALSE  TRUE
  • Удобно для поиска дубликатов
sample_id[duplicated(sample_id)]
[1] "S02" "S01"
duplicated() не отмечает первое появление

Для c("A", "A") результатом будет c(FALSE, TRUE). Функция отмечает второе и последующие появления уже встречавшегося значения.

6.5 Пропущенные значения

Пропущенное значение обозначают NA.

  • Функция is.na() показывает, какие элементы вектора пропущены:
measurements <- c(4.2, NA, 5.7, 6.3)

is.na(measurements)
[1] FALSE  TRUE FALSE FALSE
NA нельзя искать с помощью ==

Выражение measurements == NA не проверяет наличие пропусков. Для этого используют is.na(measurements).

  • Если пропуск участвует в вычислении, результат обычно тоже неизвестен:
mean(measurements)
[1] NA

У подобных функций есть аргумент na.rm = TRUE (по умолчанию FALSE), который сообщает функции, что перед вычислением пропущенные значения нужно исключить:

mean(measurements, na.rm = TRUE)
[1] 5.4
Как na.rm = TRUE влияет на среднее

Без na.rm = TRUE функция mean() возвращает NA: среднее неизвестно, если среди исходных значений есть пропуск.

С na.rm = TRUE среднее считается только по трём известным значениям, то есть количество участвующих в расчёте элементов уменьшается.

Сам исходный вектор не меняется, и NA остаётся внутри measurements.
